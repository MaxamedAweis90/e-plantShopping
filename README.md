# Paradise Nursery Shopping Application

**e-plantShopping** is an online plant store application built with React, Vite, and Redux Toolkit. It allows users to browse a curated selection of houseplants across multiple categories, view details, manage quantities in an interactive shopping cart, and track total expenses dynamically.

## Features

- **Landing Page**: Introduction to Paradise Nursery with background imagery, mission statement, and quick navigation.
- **Product Catalog**: Categorized plant listings (Air Purifying, Aromatic, and Low-Maintenance) with live "Add to Cart" availability toggles.
- **Dynamic Header & Navigation**: Real-time counter of total cart items visible across views.
- **Interactive Shopping Cart**: Detailed view of selected plants, individual subtotal calculations, dynamic increment/decrement controls, item deletion, and checkout placeholder.

## Tech Stack

- **Frontend**: React (Functional Components, Hooks)
- **State Management**: Redux Toolkit & React-Redux
- **Styling**: Vanilla CSS3
- **Build Tool**: Vite
